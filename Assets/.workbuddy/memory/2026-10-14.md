# 2026-10-14

## PpocrHand 手写识别功能（新增）
- 新增 `ppocr/Scripts/PpocrHand.cs`：Unity 手写画板 MonoBehaviour。鼠标在白底画板上写字，`OnGUI` 实时落墨（线段插值避免断点），点“识别”后裁剪墨迹外接框送识别，显示按置信度降序的 top-K 候选字与裁剪预览。
- `TextRecognizer` 新增 `RecCandidate`（`Text`/`Score`）、`RecognizeCandidates(ImageBuffer,int topK)`、`PreprocessSingle`、`CtcBeamSearch`（log 空间前缀集束搜索，类剪枝 expandTopK=30、beamWidth=topK+2）及 `LogAdd`/`GetLog`/`TopKClasses` 辅助。
- `OcrPipeline` 新增 `CreateRecognizerOnly`（同步）+ `CreateRecognizerOnlyAsync`（协程）：仅加载识别器，手写场景免去检测模型开销。
- `ImageBuffer` 新增 `Crop(x,y,w,h)` 与 `UploadToTexture(Texture2D)`（翻转上传，画板实时刷新）。
- `Editor/PpocrSceneMenu.cs` 新增菜单 `Tools/PPOCR/Create Handwriting Scene` 一键生成场景。
- 验证：复用 `/c/tmp/ocrtest` 编译核心文件（0 错）；新建 `/c/tmp/handtest` 把 `PpocrHand.cs` 也编入（扩展 UnityStub）并跑真实模型冒烟测试：合成交叉笔画 `RecognizeCandidates(5)` 返回 `X 98.79% / x 1.04% / × 0.13% / χ 0.01% / 乂 0.01%`，降序、概率和=1.0，top1 与贪心一致。
- 修复的 bug：`CtcBeamSearch` 原仅枚举 `pb.Keys` 做展开/收尾，会丢失只含 `pnb` 的前缀导致返回 0 候选；改为枚举 `pb`+`pnb` 并集（每次时间步剪枝与最终归一化都修）。
